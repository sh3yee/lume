# Lume Markdown 语法与操作指南

[English](markdown-guide.md) | **简体中文**

## 编辑方式与通用操作

### 先区分两种编辑方式

| 方式       | 如何操作                                                                       | 适合的场景                                |
| ---------- | ------------------------------------------------------------------------------ | ----------------------------------------- |
| 所见即所得 | 直接编辑排版后的正文；语法输入后可转换为对应内容，使用选区工具栏和右键菜单调整 | 日常写作、表格、任务、图片和公式编辑      |
| 分栏预览   | 左侧编辑 Markdown 原文，右侧查看只读渲染结果，两侧支持同步滚动                 | 检查语法、批量修改源码、查看 Mermaid 图表 |

通过「偏好设置 → 编辑」选择模式，也可以按 `Ctrl+P` 打开命令面板，执行「切换编辑模式」。

下文的“点击编辑”“浮动工具栏”“右键转换”等，除特别说明外，均指**所见即所得模式**。分栏模式中的内容应在左侧源码区修改，右侧预览不直接改写文档；可以选择文字并复制，也可以点击支持的链接和目录项。

代码示例展示的是文件中的 Markdown 原文。需要一次插入完整示例时，可在分栏源码区粘贴，再切回所见即所得。直接在所见即所得中粘贴时，编辑器会识别明确的 Markdown 结构；需要保留字面文本时使用 `Ctrl+Shift+V`。

本文用 `Ctrl` 表示 Windows / Linux 的组合键；macOS 通常使用 `Command` 替代。`Enter` 表示回车键。

### 选中文字与选中对象

| 当前目标             | 如何选中                           | 可用操作                                                                   |
| -------------------- | ---------------------------------- | -------------------------------------------------------------------------- |
| 普通文字             | 鼠标拖选或使用键盘扩展选区         | 加粗、斜体、删除线、行内代码、设置链接、复制；更多操作见右键菜单           |
| 图片                 | 单击图片                           | 图片对齐、编辑说明、缩放和恢复尺寸等图片操作                               |
| 表格                 | 将光标放入单元格，或拖选多个单元格 | 增删行列、整列对齐、删除表格；选中单元格文字时显示文字格式操作             |
| 行内公式             | 单击选中，双击编辑                 | 编辑 LaTeX 源码、复制源码、删除公式                                        |
| 公式块               | 单击公式块                         | 在原位置展开源码编辑区和实时预览                                           |
| 代码                 | 在代码块内选择文字                 | 复制选中代码、剪切、粘贴纯文本；整块复制和语言设置另有入口                 |
| HTML                 | 使用原位置的源码入口或右键菜单     | 编辑 HTML 源码、复制节点 Markdown；HTML 对象不额外显示“源码节点”浮动工具栏 |
| 跨不同类型的混合选区 | 同时选择文字和其他块或对象         | 以复制、剪切为主，不统一套用文字格式                                       |

普通文字只有光标、没有文字选区时，不会因为单击就出现文字格式工具栏。表格和对象有各自的触发方式。

右键点在已有选区内，保留该选区；点在选区外，按新位置或新对象生成菜单。菜单中的灰色项目表示当前结构下无法执行。

「转换当前块」修改当前段落或容器的类型；「在当前块后插入」新增内容，通常不会替换原来的正文。YAML 元数据是例外，始终插入文首。

原位源码编辑中的修改通常会直接进入文档。「完成」「收起」或 `Escape` 不统一代表取消修改；需要撤回已输入的内容时使用撤销，属性对话框则可使用其中的取消按钮。

### 按需开启扩展

入口为「偏好设置 → Markdown」。

| 设置              | 默认状态 | 作用                                    |
| ----------------- | -------- | --------------------------------------- |
| 高亮              | 关闭     | 将 `==重点==` 显示为高亮文字            |
| 下标              | 关闭     | 将 `H~2~O` 显示为下标                   |
| 上标              | 关闭     | 将 `X^2^` 显示为上标                    |
| 行内公式          | 开启     | 渲染 `$...$` 行内公式；不控制独立公式块 |
| Mermaid 图表      | 开启     | 在分栏预览中渲染 `mermaid` 代码块       |
| 自动识别网址      | 开启     | 将裸网址等自动识别为链接                |
| 表情符号          | 开启     | 显示表情短代码并提供补全                |
| GitHub 提示块样式 | 开启     | 为五类提示块显示对应样式                |

表情补全默认采用手动触发，也可以改为自动触发。设置会保存到本地。关闭相关格式显示时，其标记或源码仍可保留在文档中；不需要为了临时查看原文删除内容。

## 块元素

### 段落和换行

在普通正文中按 `Enter` 创建新段落，按 `Shift+Enter` 在段内换行。

```markdown
这是第一段。

这是第二段。
```

在源码中，两个段落之间留一行空行。普通的单个源码换行不保证显示为强制换行；需要明确换行时，可在行尾保留两个空格后换行，或使用支持的 `<br>`。

列表、表格、代码、公式和 HTML 源码区分别有自己的回车行为，不应将正文换段方式套用到所有内容。

### 标题

```markdown
# 一场阅读

## 记录与思考

### 值得继续追问的问题

###### 六级标题
```

- 在段落开头输入一至六个 `#` 和空格，先保留源码，`#` 标记显示为蓝色；输入标题文字后，在行尾按 `Enter` 转换为对应级别的标题，并进入下一行正文。
- 右键选择「转换当前块 → 转为 N 级标题」，可修改当前标题或段落的级别。
- 使用 `Ctrl+Alt+1` 至 `Ctrl+Alt+6` 转换为对应标题。
- 使用 `Ctrl+Alt+0` 或「转为正文 / 退出所在容器」恢复普通正文；在列表、引用内，这个动作会优先处理所在容器。
- 点击右侧大纲或文内目录中的标题可跳转。右侧大纲通过 `Ctrl+Shift+O` 显示或隐藏。

### 引用文字

```markdown
> 把值得记住的话留下来。
>
> 引用也可以包含多个段落。
>
> > 这是更深一层的引用。
```

- 在段落开头输入 `>` 和空格，开始引用。
- 对已有段落使用右键菜单的「所选块转为引用」，或按 `Ctrl+Shift+B`。
- 引用内可以继续输入正文、行内格式、列表等内容。
- 需要退出时，将光标放在相应段落，使用「转为正文 / 退出所在容器」。嵌套结构可逐层退出。

### 无序列表与有序列表

```markdown
- 阅读一章
- 摘录一段
  - 写下自己的理解

1. 收集材料
2. 整理结构
3. 完成初稿
```

- 段落开头输入 `- `、`* ` 或 `+ ` 创建无序列表；输入 `1. ` 等序号创建有序列表。
- 有内容的列表项中按 `Enter` 拆分并继续下一项；空列表项中按 `Enter` 可退出当前层级。
- `Tab` 增加当前项的缩进，`Shift+Tab` 减少缩进或退出列表。缩进需要有可以归属的前一项，无法执行时保持原结构。
- 右键也提供「增加所选项缩进」「减少所选项缩进 / 退出列表」。
- `Ctrl+Alt+7` 转为有序列表，`Ctrl+Alt+8` 转为无序列表。光标已在列表中时，切换作用于所在的整个列表。

### 任务列表

```markdown
- [ ] 读完这一章
- [x] 整理阅读提纲
```

1. 输入 `- ` 进入无序列表。
2. 在列表项开头继续输入 `[ ] ` 创建未完成任务，或输入 `[x] ` 创建已完成任务。末尾的空格用于确认输入。
3. 点击复选框切换完成状态，也可以在右键菜单中执行「切换当前任务项状态」。
4. 在有内容的任务项中按 `Enter`，新任务默认是未完成状态，不继承上一项的勾选状态。

任务列表可以嵌套，任务内容支持普通行内格式。分栏预览中的复选框只读；要修改状态，请改左侧 `[ ]` / `[x]`，或回到所见即所得中勾选。

### 栅栏式代码块

````markdown
```javascript
const message = '今天也写一点'
console.log(message)
```
````

**创建：**

- 右键选择「在当前块后插入 → 代码块」，或按 `Ctrl+Alt+C` 在当前块后插入代码块。
- 也可在空段落先输入三个反引号，再接 `javascript` 等可选的小写语言标记，最后输入一个空格触发转换。
- 已有完整围栏内容可在源码区输入或粘贴。

**编辑与退出：**

- 点击代码区直接编辑，`Enter` 在代码内换行，`Tab` 用于缩进。
- 点击代码块左上角的语言名称，搜索并选择语言；右键「设置代码语言」可直接填写语言标记。
- 点击「复制代码」或右键「复制整块代码」，复制不含 Markdown 围栏的代码正文。
- 在代码中拖选文字后，可复制或剪切所选部分，粘贴按纯文本处理，不会在代码里插入富文本表格等内容。
- 按 `Ctrl+Enter` 退出到代码块后的正文；右键也可在代码前、后插入段落。
- 在代码边界使用方向键，可移到相邻正文。

当前编辑区为 JavaScript、TypeScript、HTML、CSS、JSON、Markdown、Python、Rust、Java、C/C++、Go 和 SQL 提供对应的语言编辑支持。其他语言仍可保留为代码文本；高亮效果可能不同。

### 数学公式块

```markdown
$$
E = mc^2
$$
```

1. 在独立空段落输入 `$$`，按 `Enter` 创建公式块。
2. 输入 LaTeX 源码，下面会实时显示公式预览。
3. 普通 `Enter` 在公式源码中换行；点击完成按钮或按 `Ctrl+Enter`，完成编辑并回到后面的正文。
4. 再次单击公式块，可在原位置继续修改。

源码第一行按上方向键可返回前方正文，最后一行按下方向键可返回后方正文。源码为空时，按 `Backspace` 或 `Delete` 会移除公式块，并在原位置恢复可输入的正文。

右键可以复制公式源码或删除当前公式。公式块使用 KaTeX 渲染；不执行计算，支持的 LaTeX 命令以渲染器能力为限。块级公式不受「行内公式」设置控制。

### 表格

```markdown
| 主题 |  状态  |       备注 |
| :--- | :----: | ---------: |
| 阅读 | 进行中 |     第三章 |
| 写作 | 待开始 | 留出半小时 |
```

**创建表格：**

- 在单独段落中输入 `| 主题 | 状态 |`，把光标放在行末按 `Enter`，生成对应列数的表格，并进入第一行正文。
- 或右键选择「在当前块后插入 → 表格」，插入带表头和两行正文的三列表格。
- 在源码模式中使用完整的表头、分隔行和数据行语法。

**编辑与导航：**

- 点击单元格直接输入文字。单元格中支持粗体、斜体、链接等行内内容。
- `Tab` 移动到下一单元格，`Shift+Tab` 返回上一单元格。
- `Enter` 或 `Ctrl+Enter` 在表格后插入正文并退出表格，不用于新增数据行。
- 将光标放进单元格，可使用表格浮动工具栏；需要更多操作时，右键打开「当前表格 / 所选行列」。
- 菜单支持上方 / 下方插入行、左侧 / 右侧插入列、删除所选行列，以及整列左对齐、居中、右对齐。
- 拖选多个单元格时，按单元格选区处理；在单元格内部选择文字时，按文字选区处理。列对齐会修改选中范围对应的整列。

表头和至少一行正文需要保留，相关删除行操作可能禁用。要去掉整张表，请选择「删除整个表格」。如果整张表已无任何文字或行内对象，按 `Backspace` 也可移除空表。

### 脚注

```markdown
一个想法值得补充说明[^reading]。

[^reading]: 这里写补充材料，也可以使用 **粗体** 和链接。
```

- 在正文输入 `[^标识]`，在独立段落输入 `[^标识]: ` 并填写定义；相同标识将引用与定义连接起来。
- 没有对应定义时，引用可能暂时保留为普通文字；补上定义后再识别为脚注。
- 鼠标悬停在脚注引用上，可以查看定义内容的文字提示。
- 单击脚注引用，原位置展开 `[^标识]`，可修改引用的标识；按 `Enter`、`Escape` 或移出焦点结束编辑。`Escape` 用于结束编辑，不代表撤销修改。
- `Ctrl+单击` 引用跳转到定义；右键「跳转 / 编辑脚注定义」也可到达定义。
- 定义区中的 `↩` 返回对应引用。

修改引用标识不会自动替你创建同名定义。若改成不存在的标识，可能恢复为普通源码文字；需要同时补齐或调整定义。分栏预览提供脚注显示及引用、定义之间的跳转。

### 水平线

```markdown
上半部分。

---

下半部分。
```

- 在独立段落输入 `***`、`---` 或 `___`，把光标放在行末按 `Enter`，转换成分割线并进入后续正文。
- **文档第一段的 `---` 优先创建 YAML 元数据**。需要在文首插入分割线时可使用 `***`，或右键「在当前块后插入 → 分割线」。
- 单击分割线选中对象，右键可在前后插入段落或删除。
- 选中分割线后，方向键用于移到前后内容；按 `Enter` 继续写后面的正文。

### YAML Front Matter

```markdown
---
title: 阅读笔记
tags: [阅读, 写作]
---

这里开始写正文。
```

1. 在文档第一段输入 `---` 并按 `Enter`，进入元数据编辑区。
2. 直接填写 YAML，普通 `Enter` 在元数据内部换行。
3. 在末尾独立一行输入 `---` 后按 `Enter`，或直接按 `Ctrl+Enter`，回到后面的正文。

也可使用右键「在当前块后插入 → YAML 元数据（文首）」。无论当前光标在哪，元数据都放在文首；已有元数据时不能重复插入。

元数据按源码编辑，可以保留注释、多行值和自定义字段。文件中没有闭合的元数据分隔标记时，不应期待它被当成完整 YAML 块。

Lume 已使用部分文档级图片字段，例如 `typora-root-url` 和 `typora-copy-images-to`，可通过图片命令设置。复制或上传行为还受「偏好设置 → 图片」中的允许选项控制。其他自定义字段用于保存，不代表会执行 Typora 的所有配置或导出选项。

### 目录（TOC）

```markdown
[toc]

# 阅读笔记

## 第一章

## 第二章
```

- 在顶层独立段落输入 `[toc]` 或 `[TOC]`，按 `Enter` 插入目录；也可以使用右键「在当前块后插入 → 目录」。
- 目录从文档中的一级至六级标题生成，修改标题后自动更新。
- 点击目录项跳转到对应标题，重复标题也分别对应各自位置。
- 选中目录对象后按 `Enter`，可在后面继续写正文。
- 保存时保留 `[toc]` 标记，不会把自动生成的标题列表写进文件。

行内代码中的 `[toc]`、转义后的 `\[toc]` 不会生成目录。文内目录会保存在文章中，右侧大纲只是应用的导航面板，两者可以同时使用。

### 图表：Mermaid

````markdown
```mermaid
flowchart LR
  A[记录灵感] --> B[整理提纲]
  B --> C[完成文章]
```
````

- 创建代码块，将语言设为 `mermaid`，输入图表源码。
- **所见即所得中显示为可编辑代码块**，使用代码块的语言选择、复制与退出操作。
- 切换到分栏预览后，右侧将源码渲染为图表。可用于 Mermaid 支持的流程图、时序图等类型。
- 关闭「偏好设置 → Markdown → Mermaid 图表」后，预览按代码显示。
- 语法错误时保留代码内容，并显示渲染失败信息；修改左侧源码后再查看。

当前未提供 Typora 中独立的 `sequence`、`flow` / `flowchart` 围栏图表渲染。需要流程图或时序图时，请在 `mermaid` 围栏内使用对应语法。

## 行内元素

### 链接

```markdown
[阅读资料](https://example.com/notes '打开阅读资料')
```

**创建与修改：**

- 输入完整的 `[文字](地址)`，可添加可选标题。
- 选中文字后，点击工具栏的链接按钮，或右键「设置所选文字链接」，填写地址和标题。
- 普通单击链接，或把光标移入链接文字，可在原位置展开 Markdown，直接修改文字、地址和标题。
- 光标移出后收起为链接。`Escape`、`Tab` 或在源码边界用左右方向键可移出当前链接；`Enter` 会结束当前链接编辑并继续正文的换段操作。
- 未补全的链接语法会继续保留为源码。清空展开的内容会删除该链接内容。

**打开与移除：**

- 在所见即所得中使用 `Ctrl+单击` 打开链接，或右键选择「打开链接」。普通单击主要用于编辑。
- 右键可「复制链接地址」「编辑当前链接地址」「移除当前链接」。移除链接保留其中的文字。
- 分栏预览中直接点击支持的链接即可打开；有文字选区时优先处理选区。

网页链接支持 HTTP(S)。本地 `.md`、`.markdown`、`.txt` 链接需要桌面应用；相对路径以当前已保存文档的目录为基准，未保存文档需先保存。

#### 内部链接

```markdown
[跳到阅读计划](#阅读计划)

## 阅读计划
```

所见即所得中使用 `Ctrl+单击`，跳转到具有匹配锚点的标题。也可以使用文内目录和右侧大纲。

当前两种模式的标题锚点生成规则尚未统一：分栏预览使用生成的内部编号，手写 `#阅读计划` 这样的片段不保证能在预览中找到目标。跨模式导航优先使用自动生成的目录或右侧大纲。

本地文件链接中的片段，例如 `other.md#章节`，当前用于打开对应文件，尚不会自动定位到另一个文件中的标题。

#### 引用式链接

```markdown
推荐阅读 [一篇文章][article]，也可以使用 [资料库][]。

[article]: https://example.com/article '文章标题'
[资料库]: https://example.com/library
```

- 引用和定义通过方括号中的标识关联，链接定义可以放在文档其他位置。
- 在正文中编辑引用，在定义处修改目标地址；定义变化会更新对应链接。
- 定义行按 `Enter` 可转入后面的普通正文。
- 引用式链接及定义可以保存。对已有引用式链接使用「编辑当前链接地址」，会修改对应定义，同标识的其他引用随之更新。

### URL 与邮箱地址

```markdown
<https://example.com>
<reader@example.com>

https://example.com/notes
```

尖括号形式用于显式链接；启用「自动识别网址」时，普通文字中的裸网址和邮箱也可被识别。自动识别的网址可直接编辑可见文字，不使用普通显式链接的展开编辑方式。

**识别为链接和允许打开是两件事。** 当前应用的打开入口主要支持 HTTP(S)、当前文档锚点和上述本地文本文件；例如邮箱地址即使显示成链接，也没有接入调用邮件客户端的操作。需要时可以复制地址。

### 图片

```markdown
![一页阅读笔记](./assets/reading.png '阅读笔记配图')
```

**插入：**

- 按 `Ctrl+Shift+I` 或在命令面板执行「插入图片」，创建图片占位，并在原位置填写图片路径。
- 使用「插入本地图片…」选择文件，也可以粘贴截图、拖放图片文件或使用网络图片地址。
- 在所见即所得中输入完整图片语法后，按空格或 `Enter` 可转换为图片；使用 `Enter` 时还会提供后续正文位置。
- 图片路径编辑区可修改 Markdown 内容，`Enter` / `Tab` 确认，或使用本地选图按钮。原位编辑主要用于占位、空地址图片；已有图片可通过属性入口修改。

**调整：**

- 单击图片选中对象，显示图片工具栏和缩放手柄。
- 拖动手柄缩放，或右键「缩放图片」选择比例。
- 工具栏 / 右键菜单支持左对齐、居中、右对齐和恢复图片尺寸。
- 「替换图片 / 编辑说明」可修改地址、替代文字与标题；右键还可复制图片地址或图片 Markdown。
- 选中图片后按 `Backspace` / `Delete`，或执行「移除图片引用」，只移除文档中的引用。

**整理文件：**

右键提供「移动 / 重命名图片…」「复制图片到…」「上传图片」等入口，命令面板也提供批量处理。使用前可在「偏好设置 → 图片」选择保留原位置、复制目录、相对路径或外部上传器。

「删除图片及原文件…」与移除引用不同，会涉及磁盘图片文件，使用时应核对目标。相对路径和本地资源处理以桌面应用及已保存的文档位置为准。缩放与对齐等额外信息可能以 HTML 图片形式保存，其他 Markdown 查看器的显示效果取决于其 HTML 支持。

### 强调（斜体）

<!-- prettier-ignore -->
```markdown
*一段需要强调的文字*
_另一种斜体写法_
```

输入成对标记完成后显示斜体。对已有文字可使用选区工具栏、右键「斜体」或 `Ctrl+I` 切换。标记与内容之间不要留首尾空格；代码中的星号和下划线按代码文字处理。

### 粗体

<!-- prettier-ignore -->
```markdown
**最重要的一句话**
__另一种粗体写法__
```

使用成对双星号或双下划线；也可选中文字，使用工具栏、右键「加粗」或 `Ctrl+B`。再次执行可取消对应格式。

### 行内代码

```markdown
使用 `writeNote()` 记录内容。
```

用成对反引号包裹文字，或选中文字后使用「行内代码」 / `Ctrl+E`。行内代码按代码文本处理，内部的 Markdown 标记不会继续变成粗体、链接等格式。

选中行内代码文字时，工具栏和右键提供复制、取消行内代码等操作。将普通文字改成行内代码时，会清除该范围上不兼容的其他行内格式。

### 删除线

```markdown
~~已经不再采用的方案~~
```

使用双波浪号包裹内容，或通过文字工具栏、右键「删除线」、`Ctrl+Alt+X` 切换。单个波浪号用于可选下标语法，不作为删除线。

### 下划线

```html
<u>需要下划线的文字</u>
```

下划线通过行内 HTML 提供；`_文字_` 表示斜体。标签闭合后显示下划线，点击或将光标移入时可展开 HTML 源码，按行内 HTML 的规则编辑和收起。

### 表情符号

```markdown
今天完成了一小步 :smile: :sparkles:
```

- 启用「表情符号」后，已收录的短代码显示为表情，普通 Unicode 表情也可以直接输入。
- 输入 `:smi` 等未完成短代码后，按 `Escape` 手动打开补全列表；可在设置中改为自动补全。
- 使用上下方向键选择候选，按 `Enter` 或 `Tab` 插入；再次按 `Escape` 关闭候选列表。
- 所见即所得和分栏源码区均有补全；源码区插入的是 `:名称:`，预览显示对应表情。
- 代码、公式、链接地址及 HTML 源码等上下文不会按普通正文触发表情补全。未收录的短代码保留为文字。

### 行内数学公式

```markdown
圆的面积为 $A = \pi r^2$。
```

- 「偏好设置 → Markdown → 行内公式」默认开启。
- 输入成对 `$` 和公式内容，完成后显示公式；内容首尾不要紧贴空格。
- 单击公式选中对象，双击打开「编辑公式源码」；也可以通过公式工具栏或右键进入。
- 在 LaTeX 字段修改并保存；右键可复制公式源码或删除当前公式。
- 选中公式后，左右方向键可回到前后文字。

行内公式通过属性编辑入口修改，独立公式块使用原位源码与实时预览，两者不是同一种编辑界面。当前没有 Typora 文档中“输入 `$` 后按 Escape 开始公式提示”的交互。

### 下标

<!-- prettier-ignore -->
```markdown
H~2~O
X~long\ text~
```

先开启「偏好设置 → Markdown → 下标」，再用成对 `~` 包裹内容。需要空格时使用反斜杠转义，例如 `long\ text`。已有下标文字可以直接修改；需要检查或调整标记时切换到源码区。

### 上标

```markdown
X^2^
```

先开启「上标」，再用成对 `^` 包裹内容。`[^id]` 仍表示脚注引用，不是同一种语法。包含空格的内容与下标一样，需要转义。

### 高亮

```markdown
==这是需要再次回看的重点==
```

先开启「高亮」，再用成对 `==` 包裹内容。可直接修改高亮中的文字；需要增删分隔标记时使用源码区。下标、上标和高亮没有在普通文字工具栏中提供独立按钮，主要通过语法输入与源码编辑使用。

### 转义与字面标记

```markdown
\*这段文字保留星号\*
\[toc]
```

反斜杠可用于保留本来会触发格式的标记。讲解语法时也可以使用行内代码或代码块。需要粘贴未渲染的 Markdown 文字，可使用 `Ctrl+Shift+V`；之后继续输入时，符合条件的语法仍可能再次触发转换。

## HTML 与嵌入内容

### 行内 HTML 与文字样式

```html
<u>下划线</u>
<span style="color: red">一段红色文字</span>
<kbd>Ctrl</kbd>
<sup>上标</sup>
<sub>下标</sub>
```

- 支持范围内的完整标签显示为格式化内容。
- 点击行内 HTML，或把光标移入其中，可在原位置展开源码；不需要切到整个文档的源码模式。
- 按 `Ctrl+Enter`、`Escape`，或将光标移出 / 编辑器失焦后收起；不完整内容继续保留源码。
- `Enter` 新建段落，`Shift+Enter` 段内换行；在行内 HTML 文字末尾换段时，后续新段落不继承空标签样式。
- 普通 HTML 文字选区仍可使用文字格式操作，选中 HTML 对象则使用对应源码入口。

空标签和 `display:none` 内容在编辑器中保留可编辑入口，预览则遵循其隐藏语义。在行内 HTML 的文字中间换段时，两侧分别保留相应标签；在末尾换段时退出该 HTML 样式。

### HTML 块

```html
<details>
  <summary>阅读补充</summary>
  <p>这里放一段展开后阅读的内容。</p>
</details>
```

- 点击非交互区域、使用 `Ctrl+单击` 或对象上的 `HTML` 按钮，可展开源码；右键也提供「编辑 HTML 源码」。
- 源码展开后，下面保留预览，修改会写入文档。
- 再次点击 `HTML`、按 `Ctrl+Enter` / `Escape`，或点击对象外部，可收起源码。
- 块的外层标签已完整闭合、光标位于源码末尾时，`Enter` 收起源码并进入后方正文；在源码中间或标签未完成时，`Enter` 继续编辑，`Shift+Enter` 保持源码换行。
- 源码开头按上方向键、末尾按下方向键可回到相邻正文。清空整个 HTML 对象的源码会移除对象。

HTML 块内部按 HTML 处理，不能假定其中的 `**粗体**` 等 Markdown 一定被解析；可直接使用 `<strong>` 等标签。

从后方正文按退格键到达 HTML 块边界时，会展开源码并将光标放在末尾；从前方按 `Delete` 进入时，光标位于源码开头。展开与收起本身不会重载 iframe。清空源码后可以撤销恢复；输入法组合期间的临时空内容不会直接移除对象。

### 嵌入内容与 iframe

```html
<iframe src="https://example.com/embed" width="640" height="360"></iframe>
```

请使用提供方明确支持的 iframe 嵌入地址，示例地址仅作语法演示。嵌入内容外侧保留 `HTML` 按钮，用来修改源码；iframe 内部的点击由嵌入页面处理。

iframe 仅接受 HTTP(S) 地址，按应用的隔离规则加载。第三方网站是否允许嵌入、是否要求特定浏览器能力，会影响最终显示。不能把依赖脚本执行的分享代码视为已经支持。

### 视频、音频与 SVG

```html
<video controls src="./media/reading.mp4"></video>
<audio controls src="./media/voice-note.mp3"></audio>
```

视频和音频使用支持的 HTML 标签与播放器控件，源码通过外侧 `HTML` 按钮编辑；相对资源路径按当前文档的资源路径规则解析。能否播放取决于系统 WebView、媒体格式和资源可访问性。

SVG 也可作为 HTML 内容输入并查看，使用同一套源码编辑入口。支持的是经过筛选的标签、属性与展示样式，并非任意网页运行环境。脚本、事件属性、自定义组件等不会获得执行能力。

原始标签与属性随 Markdown 保存，显示时只应用支持的标签、属性和展示样式；`class`、`id`、`data-*`、事件属性及未知属性不会直接作用于应用页面。注释和 `script`、`style`、`meta` 等不可见内容在编辑器中保留源码入口，预览不显示可见内容。

## Lume 补充：GitHub 风格提示块

```markdown
> [!NOTE]
> 这是一段补充说明。

> [!TIP]
> 这里放一个实用技巧。
```

支持 `NOTE`、`TIP`、`IMPORTANT`、`WARNING`、`CAUTION` 五类。

- 在引用的第一个段落输入 `[!NOTE]` 等标记，按 `Enter` 转换为提示块；例如先输入 `> ` 进入引用，再输入标记并回车。
- 也可以右键「在当前块后插入 → 提示块」，选择对应类型。
- 内部直接编辑正文，并可使用格式文字、链接、列表等内容。
- 退出时使用「转为正文 / 退出所在容器」。
- 关闭「GitHub 提示块样式」后显示普通引用样式和类型标记，不意味着删除提示块内容。

| 正文段内换行                        | `Shift+Enter`                  |
| 退出代码块、公式块、YAML、HTML 源码 | `Ctrl+Enter`，具体行为见各节   |

查找替换目前面向所见即所得模式，可查看匹配、切换上一个 / 下一个、替换当前项或全部替换。它是文本匹配，不是正则表达式搜索，也不用于修改图片地址、公式属性等所有对象内部的源码。

| 项目                           | 当前行为                                                                 |
| ------------------------------ | ------------------------------------------------------------------------ |
| Mermaid                        | 所见即所得编辑代码，分栏预览显示图表                                     |
| 独立 Sequence / Flowchart 围栏 | 未接入专用渲染；使用 Mermaid 对应语法                                    |
| 源码区查找替换                 | 尚未提供与所见即所得相同的查找替换面板                                   |
| 手写标题锚点                   | 两种编辑模式的标题锚点规则尚未统一，跨模式导航优先使用目录或大纲         |
| 邮箱与其他协议                 | 能显示或保存地址，不代表已接入打开对应外部应用                           |
| 跨文件标题锚点                 | 可打开支持的本地文件，尚不自动定位文件内片段                             |
| HTML                           | 支持常见标签及部分属性、样式，不能执行任意脚本或完整网页                 |

本说明依据当前仓库的语法扩展、输入规则、菜单和键盘处理核对，表示已有实现入口；未将全部场景视为已完成桌面端实操验收。复杂嵌套、媒体资源和跨模式保存，建议先在文档副本中确认效果。
