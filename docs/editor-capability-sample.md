## 右键验收流程

1. 在正文选中“粗体”后右键选区内：目标应仍是该选区。
2. 选中第一段文字，再右键其他段落或图片：目标应切换到点击处。
3. 对带粗体、链接和多段结构的内容执行块转换：格式与多段结构应保留。
4. 在 Lume 复制 A，再到其他应用复制 B，回到 Lume 右键粘贴：应得到 B。
5. 对图片、链接、表格单元格、代码、公式分别右键：只有适合该目标的动作可执行。
6. 表格中分别选择文字和多个单元格，检查菜单和操作对象。
7. 代码里复制粘贴保留缩进；代码外粘贴 Markdown 应走 Markdown 粘贴规则。
8. 在窗口右下角打开菜单及插入子菜单，检查边界和键盘导航。
9. 在所见即所得中改一个普通字，保存，切换源码检查整份文件的链接定义、围栏元数据、脚注、任务状态及图片属性。
10. 关闭文件后重新打开，在两种模式再次检查正文与属性。
11. 勾选嵌套任务，撤销、重做，保存重开；预览中的复选框应只读。
12. 在公式源码、图片说明和链接面板中分别取消和保存；面板打开后切换文档，旧目标不能修改新文档。
13. 对表格列设置对齐，增加行列，保存后从源码确认整列对齐；表头和最后一行正文的删除入口应禁用，删除整表应可用。
14. 用带 `width` / `height` 的 HTML 图片检查保留策略：不支持的图片属性显示为源码，编辑其他正文后属性仍应存在。
