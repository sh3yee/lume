# Lume 产品路线图

[English](roadmap.md) | **简体中文**

这里记录后续方向与优先级，不重复维护已完成功能的清单。当前功能和操作方式请参阅 [项目介绍](../README.zh-CN.md) 与 [Markdown 语法与操作指南](markdown-guide.zh-CN.md)，开发配置参见 [开发说明](development.zh-CN.md)。

以下事项仍需完善或评估，不代表已提供，也不承诺具体发布时间。

当前以仓库 **0.8.0** 的实现为基础：本地文件栏与文件管理、文档标签、源码高亮、简体中文与英文界面，以及深浅主题下的玻璃侧栏均已提供。近期重点是完善这些功能的日常使用体验，并补齐查找、文件导航与导出能力。

## 产品原则

- 本地优先：直接使用本地 Markdown 文件，文档由用户掌控。
- 写作优先：优先保证输入、光标、选区、撤销和保存的可靠性。
- Markdown 优先：维持内容的可读性和可迁移性。
- 保留两种编辑方式：所见即所得与源码分栏分别服务不同写作习惯。
- 按实际需求扩展功能，保持日常编辑流程清晰。

## 近期优先事项

### 编辑与保存的可靠性

- 持续完善中文输入法组合输入、文字与对象选择，以及复制、剪切和粘贴行为。
- 检查表格行列与整表删除、图片缩放、链接、脚注、公式和 HTML 的编辑边界，保证撤销、切换模式与保存重开后的内容完整。
- 明确允许的 Markdown 排版规范化与必须保留的正文、地址和属性。
- 完善自动保存、外部修改、文件移动与重命名、删除和会话恢复之间的配合，优先保护未保存内容与冲突文档。

### 两种编辑模式的一致性

- 为源码编辑区补充查找、替换和匹配定位。
- 完善源码高亮与实际 Markdown 解析的一致性，改善长行、换行和行号对齐。
- 统一标题锚点规则，检查重名标题、嵌套标题、目录与大纲在两种模式中的定位。
- 改善复杂文档中的同步滚动和跨模式撤销体验。
- 缩小 Mermaid、HTML / 媒体等内容在两种模式中的展示与操作差异，并在操作指南中说明支持边界。

### 本地文件与资源

- 提供最近文件与工作区历史列表。
- 增加按文件名快速打开，补充当前以操作命令为主的命令面板。
- 完善文件树的键盘导航、拖放移动、操作失败提示，以及文件变化后的选中状态和路径同步。
- 完善通用附件、相对路径和本地文档链接的插入流程。
- 改善图片文件定位、资源整理和失败后的恢复体验。

### 界面与跨平台体验

- 统一标题栏、文件栏、大纲和浮层在深浅主题中的材质、接缝与文字对比度。
- 检查侧栏缩放、窄窗口浮层、独立字号和长文件名下的布局与可操作性。
- 完善简体中文与英文界面的翻译一致性，检查长文案、菜单、快捷键提示和错误信息。
- 核对 Windows、macOS 与 Linux 的字体、窗口操作和系统剪贴板差异。

## 后续方向

| 方向       | 计划                                                   |
| ---------- | ------------------------------------------------------ |
| 工作区搜索 | 按文件名、正文、标题等检索，评估后台索引与文件监听开销 |
| 阅读与导出 | HTML / PDF 导出，完善长文阅读与导航                    |
| 大文档性能 | 优化源码高亮、实时解析与预览更新，评估分块解析和虚拟化 |
| 内容表达   | 根据使用需求扩充图表与 HTML / 媒体兼容范围             |
| 文档组织   | 评估标签、收藏、反向链接与版本历史                     |
| 个性化     | 评估自定义主题、模板和快捷键                           |
| 可选同步   | 评估 WebDAV、Git 和自托管方案，保持本地写作独立可用    |
| 扩展能力   | 评估受控插件接口与权限边界                             |
