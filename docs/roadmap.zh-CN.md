# Lume 产品路线图

[English](roadmap.md) | **简体中文**

这里记录后续方向与优先级，不重复维护已完成功能的清单。当前功能和操作方式请参阅 [项目介绍](../README.zh-CN.md) 与 [Markdown 语法与操作指南](markdown-guide.zh-CN.md)，开发配置参见 [开发说明](development.zh-CN.md)。

以下事项仍需完善或评估，不代表已提供，也不承诺具体发布时间。

## 产品原则

- 本地优先：直接使用本地 Markdown 文件，文档由用户掌控。
- 写作优先：优先保证输入、光标、选区、撤销和保存的可靠性。
- Markdown 优先：维持内容的可读性和可迁移性。
- 保留两种编辑方式：所见即所得与源码分栏分别服务不同写作习惯。
- 按实际需求扩展功能，保持日常编辑流程清晰。

## 近期优先事项

### 编辑与保存的可靠性

- 持续完善中文输入、对象选择、鼠标与键盘操作，以及系统剪贴板交互。
- 检查图片、表格、链接、脚注、公式和 HTML 的编辑、撤销、切换模式与保存重开。
- 明确允许的 Markdown 排版规范化与必须保留的正文、地址和属性。
- 完善自动保存、外部修改、重命名、删除和会话恢复之间的配合。

### 两种编辑模式的一致性

- 为源码编辑区补充查找、替换和匹配定位。
- 统一标题锚点规则，改善目录、大纲与跨模式跳转。
- 改善复杂文档中的同步滚动和跨模式撤销体验。
- 扩充长文档、复杂嵌套及错误语法的兼容检查。

### 本地文件与资源

- 提供最近文件与工作区历史列表。
- 增加按文件名快速打开。
- 完善通用附件、相对路径和本地文档链接的插入流程。
- 改善图片文件定位、资源整理和失败后的恢复体验。

## 后续方向

| 方向       | 计划                                                |
| ---------- | --------------------------------------------------- |
| 工作区搜索 | 后台全文索引，按文件名、正文、标题等检索            |
| 阅读与导出 | HTML / PDF 导出，完善长文阅读与导航                 |
| 大文档性能 | 评估分块解析和预览虚拟化，减少输入与滚动阻塞        |
| 内容表达   | 根据使用需求扩充图表与 HTML / 媒体兼容范围          |
| 文档组织   | 评估标签、收藏、反向链接与版本历史                  |
| 个性化     | 评估自定义主题、模板和快捷键                        |
| 可选同步   | 评估 WebDAV、Git 和自托管方案，保持本地写作独立可用 |
| 扩展能力   | 评估受控插件接口与权限边界                          |

## 反馈与参与

优先欢迎可复现的编辑问题、保存问题和实际写作场景。请在 [Issues](https://github.com/sh3yee/lume/issues) 中说明操作步骤、预期结果、实际结果与系统环境，并移除示例中的私人内容。
