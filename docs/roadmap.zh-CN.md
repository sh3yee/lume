# Lume 产品路线图

[English](roadmap.md) | **简体中文**

这里只保留尚未完成的工作。已提供的功能请参阅 [项目介绍](../README.zh-CN.md) 与 [Markdown 语法与操作指南](markdown-guide.zh-CN.md)。

后续开发主要围绕用户自行选择存储的文档同步展开，让普通 Markdown 文件与配套资源可以在自己的设备间流转。WebDAV、Git 面向可自托管的存储方式；百度网盘、阿里云盘则是独立的云服务接入方向。以下接入均处于计划或评估阶段，不承诺具体发布时间。

## 主要方向

| 方向     | 后续工作                                                                                          |
| -------- | ------------------------------------------------------------------------------------------------- |
| WebDAV   | 连接指定服务器，选择远程目录，同步文档与资源，支持个人 NAS 和自托管服务。                         |
| Git      | 将本地工作区连接到仓库，提供提交、同步、历史与冲突处理，支持用户选择的 Git 托管服务及自托管仓库。 |
| 百度网盘 | 评估可用的接入方式，完善授权、目录映射，以及文档与资源同步。                                      |
| 阿里云盘 | 评估可用的接入方式，完善授权、目录映射，以及文档与资源同步。                                      |

## 同步需要解决的问题

- 保持离线本地写作可用，远程连接由用户按需启用。
- 将 Markdown 与引用资源一起同步，保留相对路径，处理移动、重命名和删除。
- 检测多端同时修改，明确展示冲突，避免静默覆盖本地或远程内容。
- 展示连接状态、待同步变更、进度与失败原因，支持中断后重试。
- 在设备本地管理凭据，明确连接、断开及同步范围的选择。

## 持续维护

继续处理可复现的编辑、保存和恢复问题，以及性能与跨平台兼容问题。完善英文长文案溢出、控件宽度不足等布局问题。其他功能需求结合实际写作和同步场景安排优先级。

## 反馈

同步需求请说明使用的存储服务、设备、目录结构，以及对多端编辑冲突的处理预期。问题反馈请在 [Issues](https://github.com/sh3yee/lume/issues) 中提供操作步骤、预期结果、实际结果与系统环境，并移除示例中的私人内容和凭据。
