# Lume 产品与开发路线图

[English](roadmap.md) | **简体中文**

本文档记录 Lume 的产品原则、技术方向、语法规划和开发阶段，按当前仓库 **0.4.0** 代码更新。开发环境、项目结构与常用命令参见 [开发说明](development.zh-CN.md)，架构重构任务参见 [重构计划](refactoring-plan.md)。

本路线图中的 `[x]` 表示已有代码实现，`[ ]` 表示尚待实现或完善。

## 产品原则

- **本地优先**：文档归用户所有，直接读写本地 Markdown 文件。
- **Markdown 优先**：内容始终可保存为可移植、可版本管理的纯文本。
- **写作优先**：键入、光标、选区、撤销和输入法体验优先于附加功能。
- **双重编辑体验**：默认提供所见即所得，同时保留 Markdown 源码与预览分栏。
- **渐进增强**：复杂能力按需引入，基础编辑体验保持稳定、轻量。

## 当前架构

| 层级          | 技术选择                           | 当前职责                                                                   |
| ------------- | ---------------------------------- | -------------------------------------------------------------------------- |
| 桌面容器      | Tauri 2                            | 窗口生命周期、系统权限、原生对话框与应用打包                               |
| 原生层        | Rust                               | Tauri 启动、插件注册、命令边界与统一错误模型                               |
| 前端          | Vue 3 + TypeScript + Vite          | 应用布局、交互状态、文件流程和界面组件                                     |
| 所见即所得    | Milkdown / ProseMirror             | Markdown 编辑、节点与选区交互、输入规则和撤销重做；代码块内嵌 CodeMirror 6 |
| 分栏编辑      | 原生 textarea + markdown-it        | Markdown 源码输入、实时预览与按滚动比例同步；源码编辑区尚未接入 CodeMirror |
| Markdown 扩展 | 成对的 Milkdown / markdown-it 扩展 | GFM、链接、脚注、公式、图表、YAML Front Matter、目录与提示块               |
| 文件与工作区  | Tauri Dialog / FS 插件 + Rust 服务 | 文件读写、目录扫描、文件管理、快照轮询与变化事件                           |
| 图片资源      | 前端图片服务 + Rust 图片服务       | 本地资源处理、复制 / 移动 / 下载、暂存与外部上传器调用                     |
| 会话与偏好    | 前端状态 + localStorage            | 标签与未保存内容恢复、上次工作区路径、窗口状态及写作 / 外观 / 图片设置     |

编辑交互留在 WebView 内完成，避免把每次按键跨进程发送到 Rust。Rust 已负责工作区扫描、外部变化检测和图片资源等系统能力，全文索引与工作区搜索仍待实现。应用命令、生命周期、文档、文件、工作区、编辑器和图片分别按职责组织，Vue 组件通过平台适配层访问原生能力。

完整文件工作流面向 Tauri 桌面环境；浏览器模式提供前端开发和基础打开 / 下载保存的降级体验。图片上传是需配置外部程序的可选能力，本地写作无需账号或上传服务。

## 路线图

### 当前真实状态

Lume 当前已具备本地 Markdown 写作的主要流程：双模式编辑、多标签、工作区文件树、自动保存、外部冲突处理、会话恢复、大纲导航与命令面板。

近期代码已补齐行内与引用式链接编辑、脚注交互、YAML Front Matter、`[toc]` 目录、GitHub 风格提示块，并扩展图片插入、路径编辑和资源整理。后续将继续覆盖 Typora 参考中的 Markdown 语法，完善编辑与保存的一致性、源码模式的查找替换和工作区检索。

## 当前优先级

1. **稳定编辑与保存**：优先验证图片、链接、脚注、表格、公式和文档块的输入、选区、撤销重做、模式切换及保存往返，持续使用已有回归入口检查核心行为。
2. **补齐 Markdown 语法**：先完善 URL 自动链接、下划线、表情短代码、上下标和高亮，再扩展独立图表语法与 HTML 内容。
3. **补齐源码模式**：实现搜索替换和匹配定位，完善源码操作与所见即所得模式之间的一致性。
4. **完善本地文件可靠性**：覆盖自动保存、外部修改 / 重命名 / 删除、会话恢复及图片资源整理的桌面场景。
5. **推进工作区检索**：依次完善最近打开记录、按文件名快速打开、Rust 后台全文索引与搜索。
6. **改善长文体验**：完善大纲 / 目录定位与滚动同步，再推进 HTML / PDF 导出；同步和插件保持后续规划。
