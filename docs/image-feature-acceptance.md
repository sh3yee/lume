# 图片功能验收清单

用于逐项验收本次图片功能改动，交互参考 [Typora 图片文档](https://support.typora.io/Images/)。

使用 Markdown 任务列表记录验收：`- [ ]` 表示待验收，`- [x]` 表示正常通过。发现异常时保持未勾选，并在文末按编号记录，例如：`A03：三张图片只插入两张`；暂不测的项目可在末尾标注 `— 暂不测`。

在 VS Code 源码中，可直接把 `[ ]` 改为 `[x]`。如需鼠标点击勾选：安装 [Markdown Checkbox Preview](https://marketplace.visualstudio.com/items?itemName=GSejas.markdown-checkbox-preview) 扩展，打开本文件，按 `Ctrl+Shift+P`，运行 `Open Interactive Checkbox Preview`。在它的交互预览中点击复选框，会同步更新此 Markdown 文件。

## 验收准备

- 默认在桌面应用的所见即所得模式操作，注明源码模式的项目除外。
- 准备一个测试 Markdown 文档、几张图片副本、一张文件名含中文和空格的图片，以及一个可访问的网络图片地址。
- 涉及路径的项目，同时检查源码和磁盘文件。
- 复制、移动和删除原文件使用图片副本测试。
- 上传项目需要先配置已安装的上传程序及参数，验证上传器会实际上传所选图片。
