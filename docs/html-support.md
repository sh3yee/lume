# HTML 兼容

HTML 扩展参考 [Typora 的 HTML 支持](https://support.typora.io/HTML/)，与普通 Markdown 共用文档、保存和撤销历史。

## 行内 HTML

`<u>`、`<span style="color:red">`、`<sup>`、`<sub>`、`<kbd>`、`<ruby>` 等共用行内容器，闭合标签后显示效果。行内可以嵌套 Markdown 格式，也可以直接修改其中的文字。HTML 实体由 Markdown 解析器转换为对应字符。

点击行内 HTML，或用方向键将光标移入其中，即可在原位置展开源码。源码沿用链接、脚注的透明无框行内编辑风格，保留正文的字号、行高和光标位置。HTML 使用等宽文字，标签与合法链接源码共用主题强调色，内容保持正文颜色；与链接源码共用自然换行规则。Ctrl / Cmd + 点击也可展开。Ctrl / Cmd + Enter、Escape、移出选区或编辑器失焦后收起。未补全的内容继续保留源码。空标签和 `display:none` 内容在编辑器中可见，预览保留原本的隐藏语义。

Enter 新建段落，Shift + Enter 在段内换行。在行内 HTML 文字末尾按 Enter 时退出 HTML 样式，新段落不继承空标签；在文字中间按 Enter 时，两侧内容保留各自的标签与样式。嵌套标签遵循相同规则，列表和表格继续使用各自的 Enter 行为。

## HTML 块

块级标签、SVG、视频、音频和 iframe 共用 HTML 对象的渲染与源码编辑。点击非交互区域、Ctrl / Cmd + 点击或通过键盘选中对象可编辑源码。预览右上方提供独立的 `HTML` 按钮；iframe、视频和音频的按钮保持可见，避免嵌入内容占满区域后无法进入源码。

HTML 对象不额外显示“源码节点”浮动工具栏，复制和编辑源码保留在右键菜单中。行内 HTML 渲染内容中的普通文字选区仍使用正文格式工具栏。

源码区以 Typora 默认 GitHub 主题的简洁风格为参考，使用浅灰背景、等宽字体和 HTML 语法高亮，并适配应用的深色主题。源码展开时保留下面的预览；仅展开或收起不会重载 iframe。修改源码实时写回文档，与正文共用撤销和重做。

清空源码（包括仅剩空白）会移除 HTML 对象，块级位置恢复为可继续输入的普通段落，行内位置保留前后文字。输入法组合期间的临时空值不会触发移除；撤销可恢复清空前的 HTML 源码。

再次点击 `HTML`、按 Ctrl / Cmd + Enter 或 Escape、点击对象外部可收起源码。源码开头按上方向键、末尾按下方向键可返回正文。折叠标题和媒体控件保留自身交互；Ctrl / Cmd 在父文档中按下时也可点击 iframe 区域进入源码，焦点位于 iframe 内时使用外侧的 `HTML` 按钮。

从 HTML 后方的正文退格到块边界时，展开源码并将光标放在源码末尾，继续退格会删除末尾字符；从前方正文按 Delete 进入时，光标位于源码开头。按钮和预览点击入口保持从源码开头进入。

HTML 块内不解析 Markdown；块的划分遵循 CommonMark。注释以及 `script`、`style`、`meta` 等不可见内容在编辑器中显示源码，在预览中不产生可见内容。

图片、视频、音频、媒体封面及子资源的相对路径使用当前文档的图片路径解析规则。HTML 块中的链接通过现有文档链接入口打开。媒体播放和远程嵌入取决于 WebView 支持及站点的嵌入策略。

## 源码与渲染规则

原始标签和属性随 Markdown 保存。渲染副本仅接受常见 HTML / SVG 标签、支持的属性及展示样式；`class`、`id`、`data-*`、事件属性和未知属性不应用到页面。脚本、样式表、外部对象及自定义组件不会获得执行能力。

iframe 仅接受 HTTP(S) 地址，并固定添加不含 `allow-same-origin` 的 sandbox；不接受调用方的 sandbox 或 srcdoc。依赖页面脚本执行的第三方分享代码没有单独的服务商白名单，应使用提供方的 iframe 嵌入地址。

统一入口位于 `src/features/editor/extensions/html`：标签与属性规则、Markdown 转换、节点结构、编辑交互和预览渲染各自集中维护。新增普通标签通常只需补充支持集合及允许的属性，无需复制解析、保存和编辑逻辑。
