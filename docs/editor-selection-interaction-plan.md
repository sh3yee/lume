## 目标与当前问题

用户选中内容后，编辑器应准确表达选中了什么、可以做什么、当前状态是什么，以及命令会作用于哪里。截图中的工具栏可以用于普通文本，但不能承担所有内容的操作入口。

当前 `WysiwygPane.vue` 的 `updateBubbleToolbar` 主要判断是否有文字、是否为图片 NodeSelection、是否涉及代码块。`TextSelectionToolbar.vue` 固定显示加粗、斜体、行内代码、清除格式与复制，没有格式激活、混合或可用性状态。图片工具栏只有对齐。鼠标松开后的非拖动分支会主动折叠非空文本选区，可能影响双击选词、三击选段等原生选择行为，需要在实施时复现和修正。

既有右键目标、结构命令、属性面板及文档身份校验可以复用，但右键命中解析器包含移动选区的行为，不能直接当作左键选区变化监听器。

## 一、区分三种交互入口

1. **文本浮动工具栏**：在非空文字选区形成后显示，以常用行内操作为主。
2. **对象与块控件**：图片、公式等对象选中时显示专属外观；代码和表格使用所在块的控件；标题、列表、引用通过块入口提供结构操作。
3. **右键菜单**：提供完整的目标操作、结构操作和通用编辑命令。

普通单击正文只放置光标，不自动弹出整套格式工具栏。文本选区、对象选区和单元格选区必须有可辨识的选中外观。同一时刻只显示一个主要浮动操作栏；右键菜单或属性面板打开时，浮动栏收起。

浮动栏通常只保留 5～7 个常用入口，其余放入“更多”；删除对象、删除行列、整块转换等动作不占据默认的高频格式按钮位置。

## 二、内容与交互矩阵

| 内容和选择方式 | 选中表现 | 主要操作与范围 |
| --- | --- | --- |
| 普通段落中的文字 | 原生文本高亮、文本浮动栏 | 加粗、斜体、删除线、行内代码、设置链接、复制；清除格式放入更多，作用于所选文字 |
| 已带格式的文字 | 文本高亮，按钮显示当前状态 | 全部具有某格式时激活；部分具有时显示混合状态；操作后立即更新 |
| 标题中的文字 | 文本浮动栏，附带当前标题级别的块入口 | 文字格式作用于选区；级别/转正文是独立的块操作，明确所涉及标题 |
| 列表、任务项、引用中的文字 | 文本浮动栏，附带所在容器入口 | 所选文字格式与列表类型、缩进、任务状态、退出引用分别表达，不用一种按钮混淆两个范围 |
| 任务复选框 | 复选框状态变化 | 点击只切换该任务完成状态，不打开文字格式栏，不破坏正文和嵌套任务 |
| 行内代码中的文字 | 文本高亮、代码文本操作栏 | 复制、取消行内代码；不提供会在 Markdown 保存时丢失的粗体/斜体等嵌套格式 |
| 链接：单击放置光标 | 光标进入链接，显示简洁链接提示 | 编辑地址、打开、复制地址、移除链接；普通单击不立即导航；Ctrl+单击打开支持的地址 |
| 链接：选择部分或全部文字 | 保留文本高亮和文字格式操作 | “设置所选文字的链接”作用于选区；“编辑当前链接地址”明确作用于目标链接，跨多个链接时不猜测目标 |
| 图片：单击对象 | 对象描边、缩放手柄、图片工具栏 | 替换/编辑说明、对齐、恢复尺寸；地址、Markdown、删除放入更多；链接图片仍以图片为主要对象，地址作为附属动作 |
| 行内或块级公式：单击对象 | 公式对象描边、公式工具栏 | 编辑源码、复制源码、更多中的删除；双击或选中后 Enter 打开源码面板 |
| 代码块：单击正文 | CodeMirror 光标，代码块自身的语言/复制控件 | 不弹出文字格式栏；代码块整体动作放在块控件与右键菜单 |
| 代码块：选择代码 | CodeMirror 原生高亮、简洁代码选区栏 | 复制所选代码；保留多行缩进和多范围选择语义，不混用整块复制 |
| Mermaid | 依当前编辑模式表现为代码或只读图表 | 所见即所得遵循代码规则；预览仅提供查看/复制，不对图表节点应用文字格式 |
| 表格：单击单元格 | 单元格光标，表格边缘控件标明当前行列 | 行列与整表动作独立于单元格文字编辑；不把单击单元格解释为选择整表 |
| 表格：选择单元格内文字 | 文本高亮、文本浮动栏 | 格式作用于所选文字，表格结构操作放入容器入口 |
| 表格：选择多个单元格、整行或整列 | 单元格背景/边界高亮、表格选区栏 | 标明“单元格/行/列”范围；复制、行列操作、列对齐；不显示文字加粗栏；GFM 必需表头和最后正文行的删除禁用并解释原因 |
| 脚注引用或定义 | 引用目标提示；定义正文仍可正常选词 | 引用提供跳转定义、查看/编辑入口；定义文字使用文本操作，定义对象操作标明脚注标识 |
| 分割线 | 整个节点的选中外观 | 删除及前后插入段落，不显示文字格式栏 |
| 通用 HTML、链接定义等源码保留节点 | 源码/对象选中外观 | 查看与复制源码、转到源码编辑；不把源码当作已渲染的富文本处理 |
| 跨段落的纯文字 | 文本高亮，必要时显示块类型“混合” | 仅提供对整个范围语义明确且可执行的动作；所有普通文本均适用时才提供统一格式操作 |
| 文字与代码、图片、公式等混合选区；全选文档 | 保留各自的选区外观、简洁范围操作栏 | 默认提供复制、剪切等完整范围操作；不选择其中一个对象作为默认目标，不静默跳过不支持的部分 |
| 源码编辑模式 | 原生 Markdown 文本高亮 | 原始文本复制、剪切、粘贴；语法辅助需单独定义，不执行所见即所得节点命令 |
| 只读预览 | 浏览器文字高亮、只读对象提示 | 复制文字/代码、打开或复制链接、图片地址；不生成编辑能力 |

## 三、统一目标、能力和状态

先从编辑器最终状态生成上下文，再决定外观和命令。上下文包括：

- 文档身份和当前编辑模式，是否可编辑。
- 选区形态：光标、文字范围、单对象、多单元格、全选；支持内嵌编辑器的选区。
- 涉及的内容类型和容器链；跨范围时检查两端与整个范围，不能只读取起点父节点。
- 明确的文字、对象、块、行列和整表操作范围。
- 格式分布：全部开启、全部关闭、混合；对象属性及结构类型的当前值。
- 命令集合及其可用性、状态和不可执行的原因。

目标优先级由选区形态决定：多单元格按单元格范围处理；显式对象选择按对象处理；非空文字范围优先保留其完整范围；只有光标时才使用命中的链接或所在块。文本范围内含图片时，不将操作对象偷偷改为某张图片。

左键从选区变化获取上下文，不移动选区。右键先按命中规则保留或重定位选区，再使用同一套上下文分析。两种入口分别选择要呈现的动作，不复制两套业务命令。

## 四、按钮与命令语义

1. 格式按钮有未开启、已开启、混合和禁用四种表现。混合格式点击时统一应用到整个适用选区；全部开启时点击统一移除。
2. 使用 `aria-pressed` 表达开启/混合，使用 `disabled` 和可访问说明表达不可执行原因。格式和属性变化时更新状态，不必反复销毁并重建工具栏。
3. 不适用于目标的动作不显示；属于该目标但当前受结构限制的动作保留并禁用，例如无法再减少缩进、无法删除最后正文行。
4. 对不兼容的混合范围，不执行“只修改其中能修改的部分”的隐式操作。需要用户缩小选区，或提供名称清楚的转换动作。
5. 清除行内格式不改变块类型、任务状态、表格对齐、代码语言或公式源码。行内代码的创建/取消按 Markdown 的真实表示能力处理。
6. 块动作明确标注范围。“整个列表改为有序列表”不能伪装成只修改所选一项；要提供选中项转换，就必须实现拆分与重新组合列表并保留嵌套。
7. 执行前恢复捕获的选区并再次检查文档与能力。浮动栏自身的同步命令执行后，基于新状态继续刷新原目标；异步属性面板的旧目标失效时关闭或拒绝提交。
8. 鼠标工具栏、右键菜单和键盘快捷键使用相同命令能力检查，避免界面隐藏了动作但快捷键仍可错误执行。

## 五、选区、焦点和定位生命周期

- 保留原生单击、双击选词、三击选段、Shift+单击、Shift+方向键、拖选、全选和 CodeMirror 多范围行为。不要根据“鼠标没有移动”就强制折叠选区。
- 拖选期间不让浮动栏遮挡指针；结束后读取最终选区再展示。键盘形成选区也能触发工具栏。
- 输入、输入法组合、对象缩放和单元格拖选期间抑制浮动栏的反复开关；结束后重新计算。滚动只更新定位，不修改内容或选区。
- 使用真实选区矩形、对象边界和工具栏尺寸定位；反向选区、多行、视口外的端点不直接合并成整个屏幕的大矩形。优先锚定可见的选择活动端，在上方不足时放到下方，并限制窗口边界。
- 完全滚出可见范围时隐藏；部分可见时按可见范围定位。滚动、窗口缩放、编辑器容器尺寸变化时合并到动画帧更新。
- 鼠标点击浮动动作保留编辑器选区；属性面板获得正常的输入焦点。取消或应用后恢复正确文档的编辑器焦点。
- 工具栏支持键盘进入、方向键移动、Home/End、Escape 返回编辑器和 Tab 离开；鼠标保留选区不能以禁止键盘焦点为代价。
- 切换文档/模式、失去有效选区、对象删除、外部内容替换或组件卸载时清理目标、浮层和事件；失焦隐藏浮层，但不得擅自改写用户选区。
- 左键浮动栏、右键菜单与属性面板采用明确的互斥状态，避免正文栏、图片栏和表格栏同时叠加。

## 六、实现落点与顺序

不增加依赖，不新增通用插件框架，不在 WysiwygPane 中继续叠加独立布尔字段。

1. **统一选区分析**：从现有 `contextTarget.ts` 提取不产生事务的选区上下文分析，保留右键命中的专有处理；覆盖对象、范围、容器和内嵌 CodeMirror 选区。
2. **统一命令状态与范围**：复用 `editorCommands.ts`、`blockCommands.ts`、`tableCommands.ts` 和属性面板执行逻辑，补齐激活/混合、禁用原因与命令范围。将属性编辑等现有菜单内动作移入共享执行入口，右键与浮动栏共同调用。
3. **浮层生命周期**：用 `useSelectionToolbar` 管理展示、快照、位置、焦点与互斥；WysiwygPane 仅连接编辑器回调和组件。
4. **按目标渲染**：复用现有 floating-toolbar 样式，建立统一浮动栏外壳；文本、图片、公式、代码和表格的独立控件按职责拆分，使用同一动作描述与状态接口。
5. **先修基础选择体验**：完成双击/三击、键盘、输入法、状态高亮、选区保护和滚动定位，再接入各对象控件和混合选区。
6. **同步右键规则并验收**：两种入口对相同动作具有相同范围和保存结果，最后执行模式切换、撤销重做、保存重开。

不能只给固定工具栏换几组图标，也不能简单按照起点节点换模板；这两种方式都无法正确处理跨段落、混合格式、单元格范围和内嵌编辑器。

## 七、验收条件

以 `editor-capability-sample.md` 的副本为基础。每项均检查目标识别、选中外观、动作范围、状态反馈和保存结果。

- 普通文字、全部粗体、部分粗体、混合多种格式，按钮状态与应用/移除范围正确。
- 标题、列表、嵌套任务、引用选词只修改所选文字；块操作保持多段、链接、图片与嵌套结构。
- 双击选词、三击选段、反向拖选、Shift+选择、键盘扩展和全选不被主动折叠。
- 单击链接不意外跳转；选择链接文字保留文字选择；编辑地址与设置所选文字链接的范围不同且可辨认。
- 图片缩放与说明编辑、公式源码编辑、CodeMirror 多行/多范围选择分别使用对应控件。
- 单元格内选词与跨单元格选择有不同外观与命令；列对齐仍能正确序列化。
- 文字跨代码、图片或公式时不会出现误导性的格式命令，不会忽略部分范围后静默修改其余内容。
- 浮动栏与右键菜单对同一个命令得到相同结果；快捷键同样遵守模式与能力限制。
- 鼠标点击工具栏、键盘进入工具栏、属性面板取消与应用不会丢失目标或把修改写入其他文档。
- 输入法、滚动、窗口边缘、不同缩放比例和长文档下无反复闪烁、遮挡与明显延迟。
- 源码与只读预览按各自模式显示动作；只读模式不能通过浮动按钮或快捷键修改内容。
- 每种修改可撤销/重做；保存、关闭、重新打开及切换模式后正文、格式和必要属性保持一致。

自动化回归覆盖选区分析、能力/状态、命令范围、选区恢复、文档失效和序列化往返。实际坐标、WebView 焦点、原生双击、输入法、缩放和视觉外观需 Windows 桌面验收；解析实验或模拟 DOM 不替代这些验收。
