## 标签与文档

- 打开文件时复用当前未修改的空白页或欢迎页，保留其他标签和有内容的草稿；批量打开时仅复用最初的空白页。
- 修复文件读取期间输入、撤销，以及编辑器内容尚未同步时草稿可能被覆盖的问题，保护正在编辑的内容。
- 重复打开同一文件时切回已有标签并保留未保存修改；Windows 下可识别大小写、路径分隔符等不同写法，避免重复标签。
- 补齐关闭最后一个标签后的空白页复用，以及源码模式和所见即所得模式下的启动恢复，正确识别旧会话中未修改的欢迎页。

## 编辑体验与界面

- 缩小查找替换浮层，默认收起替换栏，可通过左侧箭头展开；匹配计数移入查找框，并采用与应用一致的玻璃效果。
- 修复输入法组合输入期间按 Enter 意外跳转查找结果的问题。
- 无序列表按嵌套层级分别显示实心圆、空心圆和方块，更容易区分列表结构。
- 调整 Note、Tip、Important、Warning 和 Caution 提示块的图标、圆角边框与浅色背景，统一编辑和预览中的显示。
- 统一命令面板、偏好设置、侧栏新建及图片和节点属性等输入框的聚焦边框与底色，减轻聚焦光晕。

## 安装包

- Windows：提供 NSIS 安装程序（`.exe`）与 MSI 安装包；应用内在线更新使用 NSIS 安装程序。
- macOS：分别提供 Apple Silicon（aarch64）和 Intel（x86_64）版本的 DMG、应用归档及更新包。
- Linux：提供 DEB、RPM 与 AppImage 安装包；应用内在线更新适用于 AppImage。
- 安装包、签名文件及 `latest.json` 更新清单由 GitHub Actions 构建并上传，待四个平台构建及更新清单校验完成后公开发布；附件以本页实际列表为准。
- v0.8.7 用户可在「偏好设置 → 关于」检查并安装本次更新。
