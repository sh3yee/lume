## Git 版本管理

- 安装 Git 后，可从命令面板克隆仓库，或点击文件栏顶部的分支图标打开「版本管理」。在面板中可以查看文件差异、暂存并提交改动、切换分支，也可以查看提交历史并恢复文件。
- 支持获取并应用远程更新、查看推送状态和手动推送。开启定时推送后，Lume 会按设定的间隔检查并推送本地提交。
- 合并远程分支遇到冲突时，可以在面板中逐个查看冲突文件和冲突块，处理后完成合并，也可以中止本次合并。
- 修复了当前分支名为空时，远程操作面板的 Vue 类型检查错误。

## Markdown 编辑

- 高亮、下标和上标现已默认开启，可在「偏好设置 → Markdown」中分别调整。中英文 Markdown 指南同步更新了对应说明。

## 安装包

- Windows 提供 NSIS（`.exe`）和 MSI 安装包，应用内更新使用 NSIS。
- macOS 为 Apple Silicon 和 Intel 设备分别提供 DMG 安装包和应用更新包。
- Linux 提供 DEB、RPM 和 AppImage，AppImage 支持应用内更新。

四个平台的构建和更新清单校验完成后，安装包会发布到 GitHub。附件以发布页实际列表为准。
