## 新增功能

- 在「偏好设置 → 关于」查看当前版本、作者、许可证、项目主页和发布页面。
- 新增应用内在线更新：检查新版本、查看更新说明、显示下载进度，下载完成后可安装并重启。
- 更新包下载后校验签名；检查、下载或安装失败时显示提示，并支持重试。
- 安装更新前同步当前编辑内容并暂存文档会话；暂存失败时停止安装，重启后恢复文档与草稿。

## 界面与发布

- 关于页使用统一的信息列布局，集中展示项目链接，支持中英文界面。
- 下载更新时可关闭设置并继续写作；安装期间防止关闭设置或应用而中断操作。
- 发布流程自动生成签名更新包和 `latest.json` 更新清单，待四个平台构建及清单检查完成后再公开 Release。
- 补充在线更新的签名配置、发布流程和本地打包说明。

## 安装与更新

- 本版首次加入在线更新功能。现有 v0.8.5 用户需手动下载安装本版，之后可在「偏好设置 → 关于」更新到后续版本。
- Windows：提供 NSIS 安装程序（`.exe`）与 MSI 安装包；在线更新使用 NSIS 安装程序。
- macOS：分别提供 Apple Silicon（aarch64）和 Intel（x86_64）版本的 DMG、应用归档及更新包。
- Linux：提供 DEB、RPM 与 AppImage 安装包；应用内在线更新适用于 AppImage。
- 安装包、签名文件及更新清单由 GitHub Actions 构建并上传，公开发布前检查各平台更新包是否齐全；附件以本页实际列表为准。
