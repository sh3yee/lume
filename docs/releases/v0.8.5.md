## 安装包

- Windows：提供 NSIS 安装程序（`.exe`）与 MSI 安装包。
- macOS：分别构建 Apple Silicon（aarch64）和 Intel（x86_64）版本，提供 DMG 与应用归档。
- Linux：提供 DEB、RPM 与 AppImage 安装包。
- 各平台附件由 GitHub Actions 构建并陆续上传；构建期间附件可能尚未齐全，最终状态以本页附件与 Actions 结果为准。
