## 软件更新

- 「偏好设置 → 关于」中的更新说明改为渲染后的 Markdown，标题、列表、代码和链接按正文样式排版，不再直接显示 Markdown 源码。
- 支持选择和复制更新说明内容；其中的 HTTP(S) 链接通过外部浏览器打开，避免在应用窗口内跳转。

## 界面与外观

- 关于页 Logo 随应用深浅主题切换，并调整显示尺寸、透明留白与位置，使图标视觉上与下方文字左对齐。
- 重新设计深色 Logo，采用柔和深灰底、实心橙色 L 和更清晰的灰色文字线，减弱霓虹光与厚重的金属边框。

## 安装包

- Windows：提供 NSIS 安装程序（`.exe`）与 MSI 安装包；应用内在线更新使用 NSIS 安装程序。
- macOS：分别提供 Apple Silicon（aarch64）和 Intel（x86_64）版本的 DMG、应用归档及更新包。
- Linux：提供 DEB、RPM 与 AppImage 安装包；应用内在线更新适用于 AppImage。
- 安装包、签名文件及 `latest.json` 更新清单由 GitHub Actions 构建并上传，待四个平台构建及更新清单校验完成后公开发布；附件以本页实际列表为准。
- v0.8.8 用户可在「偏好设置 → 关于」检查并安装本次更新。
