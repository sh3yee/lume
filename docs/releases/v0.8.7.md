## 编辑体验

- 修复无序列表行首退格时，小圆点消失后正文仍保留列表缩进的问题；现在会退出当前列表层级，光标回到段落开头。
- 修复列表项包含引用等后续块时无法退格退出的问题，保留正文和后续内容。

## 界面与偏好设置

- 首次启动或没有有效主题记录时默认使用浅色主题。
- 恢复上次窗口的位置、尺寸及最大化状态；屏幕布局变化导致原位置不可见时自动居中，避免窗口停留在屏幕外。
- 偏好设置修改后立即保存，涵盖界面语言、主题、字体、写作排版、标签栏、状态栏及图片设置。
- 调整深色模式下侧栏、标签页和浮动工具栏的玻璃效果，并改善代码块及表格标题的背景高光。

## 发布流程

- 修复完整安装包已上传的草稿 Release 无法公开发布的问题，并支持直接校验、发布现有草稿，减少重复构建。

## 安装包

- Windows：提供 NSIS 安装程序（`.exe`）与 MSI 安装包；应用内在线更新使用 NSIS 安装程序。
- macOS：分别提供 Apple Silicon（aarch64）和 Intel（x86_64）版本的 DMG、应用归档及更新包。
- Linux：提供 DEB、RPM 与 AppImage 安装包；应用内在线更新适用于 AppImage。
- 安装包、签名文件及 `latest.json` 更新清单由 GitHub Actions 构建并上传，待四个平台构建及更新清单校验完成后公开发布；附件以本页实际列表为准。
- v0.8.6 用户可在「偏好设置 → 关于」检查并安装本次更新。
