## 界面与交互

- 调整右上角更多菜单的顺序：「命令面板」移至「偏好设置」之前，「偏好设置」置于菜单末尾。
- 「偏好设置 → 关于」中的更新说明折叠控件改用 Lucide 图标，收起时朝右、展开时朝下，并统一图标与文字的间距和垂直对齐。

## 升级提示

- Markdown 更新说明渲染已在 v0.8.9 中加入；仍使用 v0.8.8 的用户需完成更新并重启，才能使用渲染后的更新说明。

## 安装包

- Windows：提供 NSIS 安装程序（`.exe`）与 MSI 安装包；应用内在线更新使用 NSIS 安装程序。
- macOS：分别提供 Apple Silicon（aarch64）和 Intel（x86_64）版本的 DMG、应用归档及更新包。
- Linux：提供 DEB、RPM 与 AppImage 安装包；应用内在线更新适用于 AppImage。
- 安装包、签名文件及 `latest.json` 更新清单由 GitHub Actions 构建并上传，待四个平台构建及更新清单校验完成后公开发布；附件以发布页实际列表为准。
