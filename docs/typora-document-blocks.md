# YAML、目录与 GitHub 提示块

Lume 在源码、所见即所得和预览模式中支持以下 Typora 语法。Markdown 文件仍是持久化真源。

## YAML Front Matter

在文档第一段输入 `---` 并按 Enter，进入可编辑的 YAML 元数据块。普通 Enter 在块内换行；在独立行输入关闭标记 `---` 后按 Enter，或按 Ctrl/Cmd+Enter，进入后面的正文。正文中的 `---` 仍用于分隔线。

也可从所见即所得右键菜单的“在当前块后插入 → YAML 元数据（文首）”插入；元数据始终插入文首，已有元数据时禁止重复插入。

```markdown
---
title: 我的笔记
tags: [Vue, 学习]
custom:
  enabled: true
---
```

保留 YAML 原文、注释、多行内容和未知字段，不因 YAML 暂时不合法而丢失编辑内容。导入的未闭合 `---` 按普通 Markdown 处理。当前元数据用于编辑与保存，不执行 Typora 专属的导出配置或图片路径配置。

## 自动目录

独立段落输入 `[toc]` 或 `[TOC]` 并按 Enter，也可使用右键菜单插入目录。收集 H1–H6，标题变化后自动更新。点击目录项跳转对应标题；重复标题分别定位。所见即所得选中目录后按 Enter 可继续写正文。

保存时只写入 `[toc]`，不把生成的目录文本写回源文件。代码和转义后的 `\[toc]` 不生成目录。

## GitHub Style Alerts

```markdown
> [!NOTE]
> 补充说明。

> [!TIP]
> 实用技巧。

> [!IMPORTANT]
> 重要信息。

> [!WARNING]
> 警告信息。

> [!CAUTION]
> 注意事项。
```

在普通引用的首段输入对应标记并按 Enter 即可转换，或从右键菜单选择类型。内部支持普通 Markdown 内容，包括格式文字、链接、列表和引用。“转为正文 / 退出所在容器”可退出提示块。

“设置 → 编辑 → GitHub Style Alerts”提供样式开关，默认启用；关闭时显示引用样式和 `[!TYPE]` 标记，不改变文档或重建撤销历史。未知类型、转义标记和代码中的标记保持普通内容。

## 验证

`npm run test:editor` 包含以下回归用例：

- 元数据、目录和五种提示块解析与序列化往返。
- 空、无效及未闭合 YAML，转义标记，代码和普通分隔线。
- 文首输入、YAML 换行与退出、提示块转换、菜单插入和撤销。
- 中文与重复标题、H1–H6、多处目录、预览锚点和 HTML 转义。
- 实际 ProseMirror DOM 中的目录更新、点击定位、元数据编辑与提示块正文。
- 提示块内嵌套引用、列表与富文本保存后保留。

桌面手动验收：

- [ ] 从源码切换到所见即所得，再切回分栏，确认三项功能内容一致。
- [ ] 保存、关闭、重新打开文件，确认内容不丢失。
- [ ] 中文输入、撤销重做、方向键和块删除行为正常。
- [ ] 浅色、深色、毛玻璃主题下布局清晰；提示块开关即时生效并在重启后保留。
